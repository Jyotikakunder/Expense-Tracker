# 💰 Expense Tracker (CLI-Based)

A simple command-line Expense Tracker application built using Python and SQLite.  
It allows users to manage daily expenses efficiently with CRUD operations and filtering features.

---

## 🚀 Features

- ➕ Add new expenses  
- 📄 View all expenses  
- ✏️ Update existing expenses  
- ❌ Delete expenses with confirmation  
- 🔍 Filter expenses by category  
- 💾 Persistent data storage using SQLite  
- ✔️ Input validation for better user experience  

---

## 🛠️ Technologies Used

- Python  
- SQLite  
- SQL  

---
## 📂 Project Structure

```
expense_tracker.py   # Main application file
expenses.db          # SQLite database (auto-created)
``` 

---

 ## ▶️ How to Run

1. Clone the repository:
```
git clone https://github.com/Jyotikakunder/Expense-Tracker
```

2. Navigate to the folder:
```
cd Expense-Tracker
```

3. Run the program:
```
python expense_tracker.py
```

## 📸 Sample Functionality

- Add expense with date, category, description, and amount
